# Ultimate-Battle-Adventure-Game
Ultimate Battle Adventure is a turn-based combat game built using Python’s Tkinter GUI library. The game runs in a custom-designed window with a canvas-based battle arena where the knight and enemies are drawn using shapes and simple animations. Players interact through large action buttons (Strike, Defend, Heal), while health bars (ttk Progressbars) visually track both player and enemy power. The game includes level-based difficulty scaling, a heart life system, score tracking, and a save/load feature using JSON files, making it a complete interactive GUI-based game rather than a simple console program.
