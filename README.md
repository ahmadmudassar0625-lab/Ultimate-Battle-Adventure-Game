# Ultimate-Battle-Adventure-Game

Overview

Ultimate Battle Adventure is a turn-based combat game built using Python’s Tkinter GUI library. The game runs in a custom-designed window featuring a canvas-based battle arena where the knight and enemies are drawn using shapes and simple animations.

Features

- Turn-based combat system (Strike, Defend, Heal)
- Health bars using ttk.Progressbar
- Heart-based life system
- Score tracking and level progression
- Difficulty scaling as levels increase
- Save and load functionality using JSON files
- Custom GUI design with animated battle effects

How It Works

Players take control of a knight and battle through four increasingly powerful enemies. Each turn, the player must strategically choose between attacking, defending, or healing while managing health and lives. The goal is to survive all levels and defeat every enemy.

Technologies Used
- Python
- Tkinter (GUI framework)
- ttk (for styled widgets like progress bars)
- JSON (for saving and loading game data)
- Random module (for combat mechanics)
